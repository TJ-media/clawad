# 클로애드 서비스 소개 자료 (네이버 로그인 재검수 제출용)

작성 목적: 네이버 로그인 사전 검수에서 "서비스 콘텐츠가 확인되지 않는다"는 사유로 반려되어, 서비스 콘텐츠 유형을 소명하기 위해 작성하였습니다. 제출 시 아래 URL과 함께 첨부합니다.

- 서비스 URL: `https://clawad.whatsup.house`
- 설치·이용 안내 페이지: `https://clawad.whatsup.house/install.html`
- 소스 저장소: `https://github.com/TJ-media/clawad`

## 1. 서비스가 무엇인가요

클로애드는 Claude Code(터미널 기반 AI 코딩 도구)를 사용하는 개발자를 대상으로 한 광고 매체 서비스입니다. 개발자가 클라이언트 프로그램을 설치하면 Claude Code 화면 하단 상태줄에 광고 문구가 표시되고, 그 노출이 서버 검증을 통과할 때마다 리워드 포인트가 적립됩니다. 적립된 포인트는 카페 기프티콘이나 편의점 금액권 같은 정해진 모바일 상품으로 교환할 수 있습니다.

광고주가 구매한 인벤토리를 개발자에게 노출하고, 검증된 매출의 일부를 비현금성 리워드로 돌려드리는 구조입니다. 현재는 외부 사용자를 모집하기 전 폐쇄형 알파 단계로, 실사용자 확보에 앞서 로그인·설치·리워드 흐름을 운영 환경에서 먼저 검증하고 있습니다.

## 2. 화면 구성

### 2-1. 첫 화면 (로그인 전) — `/`

접속하시면 "클로애드 리워드 샵"이라는 제목과 함께 다음 내용이 보입니다.

- 현재 적용 중인 리워드 정책 수치 (예: 인정 노출 1,000회당 300P, 일일 최대 500회·150P, 최소 교환 1,500P)
- 서비스 이용약관·개인정보처리방침 링크와 시행일
- 서비스 성격을 요약한 고지 문구 3줄 (광고 표기 의무, 리워드가 비구매·비양도형이라는 점, 개발 작업 내용은 수집하지 않는다는 점)
- Google·Kakao·Naver 로그인 버튼 3개

로그인 전에도 리워드 정책과 약관을 모두 열람하실 수 있도록 되어 있습니다. 소셜 로그인은 이 세 버튼으로만 처리하며, 이메일이나 비밀번호를 입력하는 별도 가입 절차는 두지 않았습니다.

### 2-2. 로그인 후 — 리워드 샵

로그인하시면 같은 URL에서 화면이 전환됩니다.

- 상단에 현재 확정된 포인트 잔액이 표시됩니다.
- "교환하기" 탭: 전체·구독권·카페·편의점·상품권 카테고리로 상품을 필터링해 볼 수 있고, 상품마다 브랜드명·상품명·필요 포인트가 카드 형태로 표시됩니다. 포인트가 부족한 상품은 버튼이 비활성화됩니다.
- 상품을 선택하시면 쿠폰을 받으실 이메일 주소를 입력하는 창이 뜹니다. 이 주소는 해당 교환 건의 발송에만 사용하며, 발송이 끝나면 즉시 삭제합니다.
- "교환 내역" 탭: 지금까지 신청하신 교환 건과 상태(신청됨·발송 완료·발송 실패·취소됨)를 확인하실 수 있습니다.
- 화면 하단에는 "리워드는 비구매형·비양도형이며 지정 상품으로만 교환된다", "충전·양도·현금 환급을 지원하지 않는다"는 문구가 항상 표시됩니다.

### 2-3. 설치 안내 페이지 — `/install.html`

리워드 샵 첫 화면에서 링크로 연결되는 별도 페이지입니다. Claude Code 사용자가 클로애드를 어떻게 설치하고 이용하는지 처음부터 끝까지 설명합니다.

- 준비물(Node.js, Claude Code 설치 여부)
- 설치 명령 한 줄과 설치 과정에서 일어나는 일(기존 상태줄 설정 백업, 상태줄 광고 등록, 소셜 로그인 연결)
- 설치 후 Claude Code 상태줄에 실제로 어떻게 표시되는지에 대한 예시
- 포인트가 어떻게 적립되고 어떻게 상품으로 전환되는지에 대한 설명
- 상태줄 관리 명령(일시중지·재개·업데이트·제거)
- 클라이언트가 서버로 전송하는 정보와 전송하지 않는 정보를 항목별로 정리한 목록 — 코드 내용·파일 경로·터미널 명령어 등 개발 작업 내용은 전혀 수집하지 않는다는 점을 명시합니다.
- 자주 묻는 질문 4개(광고 일시중지 시 불이익 여부, 제거 시 원상복구 여부, 다중 기기 사용 가능 여부, 현금 전환 가능 여부)

이 페이지는 로그인 없이 누구나 열람하실 수 있어, 서비스가 실제로 무엇을 제공하는지 스크린샷 없이도 글만으로 확인하실 수 있습니다.

## 3. 업종·콘텐츠 형태

### 광고 유형

배너나 동영상이 아닌, 텍스트 한 줄 형태의 상태줄 광고입니다. Claude Code를 실행하는 동안 화면 하단에 광고 문구가 표시되며, 문구 앞에는 관련 법령에 따라 "[광고]" 표기가 항상 붙습니다. 현재 단계에서는 클릭 시 이동하는 랜딩페이지 기능은 제공하지 않습니다.

### 광고 업종 및 카테고리

현재 폐쇄형 알파 단계로 실제 집행 광고주와 세부 광고 문구는 아직 확정되지 않았습니다. 다만 Claude Code 상태줄을 이용하는 개발자에게 노출되는 매체 특성을 고려하여, 개발자와 직접 관련된 업종 및 콘텐츠를 중심으로 광고를 운영할 계획입니다.

- 개발자 채용 및 커리어: 잡코리아·원티드 등 채용 플랫폼의 개발 직군 채용 공고, 기업 채용 브랜딩 및 커리어 관련 정보
- 개발 정보 및 콘텐츠: 개발 정보를 공유하는 인스타그램 계정, 기술 콘텐츠 채널 및 개발자 커뮤니티의 계정·콘텐츠 홍보

향후 위 카테고리에 해당하는 사업자와 콘텐츠 운영자를 대상으로 광고 제휴 및 영업을 진행할 예정입니다. 위에 언급한 업체와 계정은 현재 확정된 광고주나 제휴처가 아니라, 향후 영업 대상으로 검토 중인 예시입니다. 실제 광고 집행 시에는 광고주와 광고 내용을 사전에 확인하여 개발자 대상 서비스의 성격에 맞는 광고만 노출할 계획입니다.

### 리워드 적립 방식

광고 노출 각각은 서버가 발급한 토큰으로 검증합니다. 클라이언트가 스스로 "노출되었다"고 신고하는 내용을 그대로 신뢰하지 않고, 서명·순번·표시 간격·일일 상한을 서버에서 확인한 노출만 인정합니다. 인정된 노출 1,000회당 300포인트가 적립되며, 하루 최대 인정 횟수와 하루 최대 적립량에 상한을 두고 있습니다. 이 수치는 정책값으로 관리되어 서비스 화면에 항상 그대로 표시됩니다.

### 리워드 활용 방식

적립은 "예상 적립 → 검증 중 → 확정" 단계를 거치며, 확정된 포인트만 교환에 사용하실 수 있습니다. 교환은 현재 카탈로그에 등록된 상품으로만 가능합니다.

- 편의점 모바일 금액권 (GS25·CU·세븐일레븐)
- 카페 아메리카노 기프티콘 (스타벅스·투썸플레이스·메가커피·컴포즈커피·빽다방·바나프레소)
- 문화상품권, 네이버페이 포인트 금액권, 배달의민족 상품권
- Claude Pro 1개월 이용권 (공식 선물하기 기능을 통해 실제 전달이 가능한 구독 상품)

알파 단계에서는 이 교환 과정을 운영자가 직접 처리하고 있습니다. 사용자가 이메일을 입력하면 운영팀이 확인 후 해당 상품을 발송하는 방식이며, 자동 발급 연동은 아직 마련하지 않았습니다.

### 현금 출금 여부

지원하지 않습니다. 포인트 충전, 사용자 간 양도, 현금 환급 기능은 서비스에 존재하지 않습니다. 적립된 포인트는 위에서 안내드린 상품으로 교환하는 것 외에는 사용하실 수 없으며, 탈퇴 시 미교환 포인트는 소멸합니다.

## 4. 네이버 로그인 이용 범위

네이버 로그인에서는 이용자 식별자 하나만 제공받습니다. 이름·이메일·프로필 사진 등 다른 개인정보는 요청 항목에서 제외하였습니다. 로그인으로 받은 식별자는 회원 구분 용도로만 사용하며, 위 3번의 상품 발송에 쓰는 이메일 주소는 로그인과 별개로 교환 시점에 사용자가 직접 입력·동의한 값만 사용합니다.

## 5. 참고 — 서비스 URL이 개발 페이지인 이유

`clawad.whatsup.house`는 실제로 운영 중인 서버이며 로그인·리워드 교환이 정상 동작하지만, 아직 일반 공개 모집을 시작하지 않은 폐쇄형 알파 단계라 첫 화면의 정보량이 많지 않습니다. 이에 서비스 콘텐츠를 한 번에 확인하실 수 있도록 `/install.html`에 별도 설명 페이지를 마련해 두었습니다. 검수 시 이 페이지를 함께 확인해 주시면 서비스에서 다루는 콘텐츠(광고 방식, 리워드 적립·사용, 현금성 여부)를 스크린샷 없이도 확인하실 수 있습니다.
