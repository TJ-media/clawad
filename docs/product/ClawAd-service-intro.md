# ☕ 코딩하는 동안, 커피값이 쌓입니다

## 클로애드 (Claw-Ad)

**Claude Code 화면 구석에 광고 한 줄. 그거 쌓이면 기프티콘으로 바꿉니다.**

---

## 3단계면 끝

```
npx clawad setup
```

1. **설치** — 위 한 줄. Claude Code, Codex 둘 다 됩니다.
2. **평소대로 코딩** — 작업 중일 때만 광고가 돌고, 손 놓으면 멈춥니다.
3. **교환** — 편의점·카페 기프티콘, 문화상품권.

---

## 그래서

**얼마나 벌리나요**
하루 최대 150P, 최소 교환 1,500P. 열흘이면 커피 한 잔입니다.
용돈 벌이는 아니고, 하던 코딩에 딸려오는 정도예요.

**내 코드 보나요**
안 봅니다. 프롬프트도 코드도 파일 경로도 터미널 명령어도 서버로 안 갑니다.
올라가는 건 광고가 화면에 떠 있던 시각. 그거 하나입니다.

**현금으로 바꿔주나요**
안 됩니다. 지정 상품 교환만 돼요. 충전·양도·환급 전부 없습니다.

**지우면 원래대로 돌아오나요**
`npx clawad uninstall` 하면 건드린 설정 전부 백업에서 복원합니다.
모아둔 포인트는 남아서 웹에서 교환할 수 있고요.
