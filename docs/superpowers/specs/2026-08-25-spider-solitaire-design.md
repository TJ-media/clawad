# 스파이더 카드놀이 설계 (CLAW-279)

## 목표

클로애드 사용자 웹의 Windows XP풍 바탕화면에 독립적인 스파이더 카드놀이 창을 추가한다. 기존 클래식 카드놀이의 CC0 영미식 카드 원화와 포인터 드래그 조작을 재사용하며, 초급·중급·고급 난이도와 원본 Windows 게임의 핵심 편의 기능을 제공한다.

## 범위

- 초급 1무늬, 중급 2무늬, 고급 4무늬 난이도 선택
- 표준 104장 스파이더 규칙과 10개 테이블 열
- 남은 카드 50장을 10장씩 다섯 번 추가 배분
- 같은 무늬 K부터 A까지 완성된 13장 묶음 자동 제거
- 반복 실행 취소와 `Ctrl+Z`
- 한 번에 하나의 유효 이동을 강조하는 힌트와 `H`
- 점수, 이동 횟수, 완성한 묶음 수 표시
- 시작 메뉴, 독립 창, 최소화·복원·종료 생명주기 연결

솔버 검증 딜, 영구 통계 저장, 온라인 순위, 애니메이션 카드 쇼는 범위에서 제외한다.

## 구조

### 규칙 엔진

`apps/user-web/spider-solitaire.js`를 CommonJS와 브라우저 전역에서 함께 사용할 수 있는 무의존성 모듈로 만든다. 덱 생성, 초기 배분, 이동 가능성 판정, 묶음 이동, 추가 배분, 완성 묶음 제거, 힌트 계산, 실행 취소용 스냅샷 복원을 담당한다.

규칙 엔진 상태는 다음 값만 가진다.

- `difficulty`: `1`, `2`, `4` 중 하나
- `tableau`: 10개 카드 배열
- `stock`: 아직 배분하지 않은 카드 배열
- `completed`: 제거된 13장 묶음의 무늬 배열
- `score`: 500에서 시작하는 현재 점수
- `moves`: 이동·배분·실행 취소 횟수
- `history`: 직전 상태 스냅샷 스택. 각 스냅샷은 `history` 자체를 제외한 게임 값만 복사한다.
- `won`: 완성 묶음이 8개인지 여부

카드에는 `id`, `suit`, `rank`, `faceUp`만 저장한다. 초급은 스페이드 8벌, 중급은 스페이드·하트 각 4벌, 고급은 네 무늬 각 2벌을 사용한다.

### 화면과 입력

`apps/user-web/games.js`는 스파이더 상태를 화면으로 렌더링하고 포인터·키보드 이벤트를 규칙 엔진에 전달한다. 10열 보드, 남은 배분 횟수, 8개 완성 슬롯, 점수·이동 횟수 상태 표시줄을 제공한다.

카드 얼굴과 뒷면은 기존 `english-pattern-playing-cards@2x.png` 스프라이트와 동일한 CSS를 사용한다. 드래그 시작 시 카드 안에서 실제로 잡은 상대 좌표를 기록하며, 묶음을 옮길 때도 그 좌표를 유지한다. 브라우저 네이티브 HTML 드래그는 사용하지 않는다.

새 게임 메뉴에는 난이도 세 개를 표시하고 현재 난이도를 체크한다. 실행 취소와 힌트 버튼도 같은 메뉴 줄에 배치한다. 키보드에서는 `Ctrl+Z`와 `H`를 지원하되, 스파이더 창이 활성 상태일 때만 입력을 가로챈다.

`apps/user-web/index.html`에는 스파이더 시작 메뉴 항목, 독립 창 마크업, `WINDOWS` 및 `GAME_IDS` 등록을 추가한다. 별도 아이콘 자산은 만들지 않고 기존 카드놀이 아이콘을 재사용한다.

## 게임 규칙

- 빈 열이나 목표 열의 맨 위 카드보다 정확히 한 단계 낮은 카드만 놓을 수 있다. 쌓을 때 목표 카드와 무늬가 달라도 된다.
- 초기 배분은 앞의 4개 열에 6장씩, 나머지 6개 열에 5장씩 놓고 각 열의 맨 아래 카드만 공개한다.
- 여러 장을 함께 옮기려면 선택한 카드부터 맨 아래 카드까지 같은 무늬이며 한 단계씩 내려가는 연속 묶음이어야 한다.
- 이동 후 원본 열의 맨 위가 뒤집힌 카드라면 자동으로 공개한다.
- 같은 무늬의 K~A 13장이 열 맨 아래에 완성되면 즉시 제거하고 100점을 더한다. 제거 뒤 드러난 카드도 자동 공개한다.
- 카드 이동과 추가 배분은 성공할 때만 실행 취소 스냅샷을 남기고 점수를 1점 차감하며 이동 횟수를 1회 늘린다.
- 실행 취소는 스냅샷 하나를 복원한 뒤 점수를 추가로 1점 차감하고 이동 횟수를 1회 늘린다. 점수는 0보다 작아지지 않는다.
- 빈 열이 하나라도 있으면 추가 배분을 거절하고 이유를 상태 표시줄에 알린다.
- 완성 묶음이 8개가 되면 승리한다.

## 힌트

힌트는 현재 보드에서 실제로 수행 가능한 이동을 열 순서대로 하나 반환한다. 가능하면 뒤집힌 카드를 공개하거나 빈 열을 만드는 이동을 우선하고, 그 다음 같은 무늬 연결, 일반 내림차순 연결 순으로 고른다. 카드 이동이 없고 추가 배분이 가능하면 스톡을 강조한다. 힌트는 상태나 점수를 변경하지 않는다.

## 오류와 경계 처리

- 잘못된 난이도는 초급 1무늬로 정규화한다.
- 다른 무늬가 섞인 묶음, 같은 열로의 이동, 범위를 벗어난 인덱스는 상태 변경 없이 거절한다.
- 빈 열이 있는 추가 배분과 소진된 스톡 배분은 상태 변경 없이 거절한다.
- 창이 닫히거나 다시 마운트되면 드래그 고스트와 이벤트 리스너를 제거한다.
- 게임 상태는 메모리에서만 유지하고 API·리워드·인증·영구 저장소와 연결하지 않는다.

## 테스트와 검증

`test/spider-solitaire.test.js`에서 난이도별 덱 구성, 54장 초기 배분, 이동 판정, 같은 무늬 묶음 제한, 빈 열 배분 금지, 완성 묶음 제거, 점수, 반복 실행 취소, 힌트, 승리를 실제 규칙 엔진으로 검증한다.

`test/user-web-games.test.js`에서는 시작 메뉴·창·게임 등록, 기존 카드 자산 재사용, 키보드 단축키 및 생명주기 연결을 검증한다. 구현은 각 규칙마다 실패하는 테스트를 먼저 실행한 뒤 최소 코드로 통과시킨다.

완료 전 `npm run lint`, `npm test`를 실행하고 로컬 브라우저에서 세 난이도의 새 게임, 단일 카드와 묶음 드래그, 배분 거절, 힌트, 반복 실행 취소, 승리 표시를 확인한다.
