# clawad

**이 패키지는 이름 별칭입니다.** 실제 클로애드 CLI는 [`@clawad/cli`](https://www.npmjs.com/package/@clawad/cli)이고, 이 패키지는 들어온 호출을 그대로 그쪽으로 넘깁니다.

```bash
npx --yes clawad setup      # 아래와 같습니다
npx --yes @clawad/cli setup
```

## 왜 있나

`clawad`는 CLI의 명령 이름입니다. 하지만 `npx`의 인자는 명령 이름이 아니라 **패키지 이름**이라, 이 별칭이 없으면 `npx clawad`는 레지스트리에서 404가 납니다. 사용자가 자연스럽게 칠 이름을 우리가 갖고 있어야 오타·사칭 패키지가 그 자리를 차지하지 못합니다.

## 버전

이 패키지의 버전은 CLI 버전과 별개입니다. 의존 범위(`^0.1.21`)가 알파 기간의 `0.1.x` 전체를 덮으므로, CLI 릴리스마다 이 패키지를 다시 게시할 필요가 없습니다. CLI가 `0.2.0`으로 올라갈 때 범위를 함께 올립니다.
