클로애드(ClawAd) 설치하기

Claude Code와 Codex로 작업하는 동안 애드워드가 화면 한켠에서 에이전트 상태와 [광고] 한 줄을 보여주고, 서버가 검증한 노출만큼 포인트를 드리는 개발자 리워드 서비스입니다.

클로애드는 Anthropic·Claude와 제휴·후원 관계가 없는 독립 서비스입니다. 광고에는 항상 [광고] 표기가 붙습니다.

1. 준비물

  • Node.js 24 이상 — node --version으로 확인하세요.
  • Claude Code 또는 Codex — 둘 중 하나 이상이 설치되어 사용 중이어야 합니다. 둘 다 쓰시면 양쪽 모두에 활동 감지 훅이 등록됩니다.
  • 지원 OS: Windows · macOS — 광고를 표시하는 오버레이 앱이 이 두 OS만 지원합니다. Linux에서는 CLI만 설치되고 광고 표시와 포인트 적립이 일어나지 않습니다.

2. 설치

터미널에 아래 한 줄이면 됩니다. 저장소를 내려받거나 회원가입을 먼저 할 필요가 없습니다.

# macOS · Linux npx --yes @clawad/cli@latest setup # Windows PowerShell npx.cmd --yes @clawad/cli@latest setup
💡 지금은 알파 기간입니다. 설치·로그인·적립 모두 바로 하실 수 있고, 기능과 정책은 아직 바뀔 수 있습니다. 문제가 있거나 의견이 있으시면 문의 창구로 알려주세요.

3. 설치하면 일어나는 일

  1. 실행 환경을 진단합니다 (Node 버전, 에이전트 설정 쓰기 권한).
  2. Claude 사용자 settings.json과 Codex hooks.json에 광고 표시 구간을 판정할 활동 감지 훅을 등록합니다(세션 식별자만 사용). 설치돼 있는 쪽에만 등록하고, 이미 쓰고 계신 다른 훅은 그대로 둡니다. 상태줄(statusLine) 설정은 건드리지 않습니다. 이전 버전이 이 자리를 쓰고 있었다면 원래 설정으로 되돌립니다.
  3. 데스크탑 오버레이 앱(Claw-Ad)을 함께 설치합니다 — 약 110MB를 내려받습니다. 트레이에 상주하며, 광고는 애드워드 아래 [광고] 표기와 함께 한 줄로 표시됩니다. 광고를 표시하는 창구는 이 앱뿐이라, 설치하지 않으면 광고도 포인트 적립도 발생하지 않습니다.
  4. 광고를 미리 받아 두는 자동 동기화(sync)를 등록합니다 — 광고 표시는 네트워크 없이 로컬 캐시만 읽어 에이전트를 느리게 하지 않습니다.
  5. Google·Kakao·Naver 소셜 로그인으로 계정을 연결합니다.

터미널은 바꾸는 항목을 짧게 알리고 이 페이지를 안내합니다. 오버레이 앱 설치는 관리자 권한이 필요하지 않고, 실패해도 CLI 설치는 계속됩니다.

오버레이 앱이 표시 기능을 위해 단말 안에서 읽는 항목(세션 표시 이름·컨텍스트 사용량·작업 폴더 등)은 서버로 전송하지 않으며, 항목과 목적은 개인정보처리방침 제1장 바.에 고지돼 있습니다.

알파 빌드는 아직 코드 서명이 없습니다. macOS에서는 사용자 홈의 응용 프로그램 폴더에 설치되며(시스템 영역을 건드리지 않습니다), 릴리스 페이지에서 파일을 직접 내려받아 열면 macOS나 Windows SmartScreen이 경고를 띄울 수 있습니다 — 설치는 위의 한 줄 명령을 쓰세요.

오버레이 앱은 상태줄이 비어 있을 때만 그 자리에 Claude 구독 사용량 표시를 등록합니다. 이미 쓰고 계신 상태줄이 있으면 건드리지 않으며, 앱 설정에서 끌 수 있고 제거 시 되돌립니다. 이 사용량 값은 화면 표시에만 쓰고 서버로 보내지 않습니다. 오버레이 앱은 AGPL-3.0 오픈소스입니다: clawad-overlay

설치가 끝나면 트레이에 오버레이 앱이 떠서 이렇게 표시됩니다:

4. 포인트 적립과 교환

  • 광고 노출은 서버 검증을 거쳐 예상 적립 → 검증 중 → 확정 리워드 순서로 반영됩니다. 화면의 "예상" 수치는 확정값이 아닙니다.
  • 현재 적용 중인 적립 단가·일일 상한·최소 교환 기준은 리워드 샵 첫 화면에 항상 표시됩니다.
  • 확정 포인트는 리워드 샵에서 지정 상품(모바일 쿠폰)으로 교환합니다. 리워드는 비구매형·비양도형이며 충전·양도·현금 환급을 지원하지 않습니다.

5. 관리 명령

설치에 사용한 것과 같은 npx --yes @clawad/cli@latest를 그대로 씁니다.

… status설치 상태·로그인·동기화 상태를 확인합니다.
… pause광고 표시를 일시중지합니다. 포인트와 계정은 유지됩니다.
… resume일시중지한 광고 표시를 다시 켭니다.
… update체크섬 검증을 거쳐 새 버전으로 업데이트합니다. 실패하면 이전 버전으로 자동 복귀합니다.
… uninstall활동 감지 훅·자동 동기화·오버레이 앱·전역 clawad 명령을 모두 제거하고 설치 시 변경한 설정을 원상복구합니다.

예: npx --yes @clawad/cli@latest pause

6. 어떤 정보를 보내나요?

보내는 것 (전부입니다): 노출 토큰, 노출 순번, 가명 기기식별자(로컬 생성 랜덤값), 광고 표시 시작·종료 시각, 표시 시작 신호, 회원 식별자, 클라이언트 버전.

절대 보내지 않는 것: 프롬프트, 모델 응답, 소스코드, 파일명·경로, Git 저장소명, 터미널 명령어, 환경변수, 클립보드, 접속 IP(이벤트 데이터로), MAC 주소 등 하드웨어 식별자. 클라이언트 코드가 이런 정보에 접근하지 못하도록 설계되어 있습니다.

7. 자주 묻는 질문

Q. 광고를 잠깐 끄면 불이익이 있나요?
없습니다. 끄는 동안 포인트가 적립되지 않을 뿐입니다.

Q. 제거하면 원래대로 돌아가나요?
네. 등록한 활동 감지 훅·자동 동기화 작업·오버레이 앱·전역 clawad 명령을 모두 제거하고, 설치 시 변경한 설정을 백업에서 복원합니다. 계정과 이미 확정된 포인트는 유지되어 웹에서 교환할 수 있습니다.

Q. 0.1.11 이하 버전을 쓰고 있었는데요?
그때는 클로애드가 상태줄(statusLine) 자리를 사용했습니다. 새 버전을 설치하면 그 자리를 설치 전 설정으로 원상복구하고, 이후 광고는 오버레이 앱에서만 표시합니다.

Q. 여러 기기에서 써도 되나요?
됩니다. 등록 한도 내에서 기기를 추가할 수 있고, 포인트 상한은 기기가 아니라 계정 단위입니다. 같은 계정의 여러 기기에서 광고가 동시에 표시되면 한 건만 인정되지만, 이는 제재가 아니며 불이익이 없습니다.

Q. 포인트를 현금으로 바꿀 수 있나요?
아니요. 리워드는 지정 상품 교환 전용입니다.
